# AI-Powered Market Operations Console

Next.js application using the App Router and TypeScript.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Application routes and the
root layout live in `src/app`.

## Validation and production

```bash
npm run lint
npm run typecheck
npm run build
npm start
```

To deploy, import this repository into [Vercel](https://vercel.com/new) or use a
host that supports Next.js. The production build is created with `npm run build`.
